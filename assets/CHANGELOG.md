# Modu changelog

Details, installation limits and historical releases: https://github.com/sobranie2406/modureader/releases

## 1.0.9

- Check updates at launch; manually check, download, cancel and open installers from About.
- Prefer Gitee for app updates, fall back to identical GitHub assets, and verify size and SHA-256 before installation.
- Download embedding models on demand from Hugging Face (default) or Gitee; installers no longer include model weights.
- Reuse verified models and original licenses; assemble E5 parts automatically. Stable release, build 10027.

- 启动检查更新；关于默读中可检查、下载、取消并打开安装器。
- 应用更新优先 Gitee，失败后下载 GitHub 同一安装包，安装前核对大小和 SHA-256。
- 向量模型按需从 Hugging Face（默认）或 Gitee 下载，安装包不再内嵌模型权重。
- 复用已校验的模型并保留原许可证，自动合并 E5 分片。正式版，构建号 10027。
