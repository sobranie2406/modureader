# AI 与书籍索引

书架书籍菜单的「向量化／重新向量化」是统一的手动建库入口，自动索引也使用后台队列。
AI 阅读窗口不再另建一份知识库，也不再绕过队列同时写入同一个索引文件。
向量模型设置负责选模型；大语言模型设置负责回答问题，两者不是同一种模型。

| 使用场景 | 原文及索引来源 |
| --- | --- |
| 书内自由对话 | 从当前书的有效索引做关键词和向量混合检索，附带片段标识送给大模型 |
| 首页自由对话中的书籍问题 | 先通过书架工具确定书籍 ID，再由书籍搜索工具优先检索该书索引；需要模型支持并启用工具调用 |
| 本章总结、概念解释、论证分析、摘录、阅读指南、词汇、思维导图 | 使用选中文字或当前章原文，不引入其他章节的检索片段 |
| 智能翻译 | 只使用选中文字 |
| 全书总结 | 按目录覆盖各章，优先复用有效索引的章节文本，缺失时从阅读器提取；按上下文预算压缩，不等同逐字阅读全文 |
| 人物追踪 | 复用已读章节的索引文本，当前章节只读取至当前位置；阅读器无法提供已读范围时停止，不用整章替代 |

安全及降级规则：

- 查询向量必须与索引的模型、模式及维度匹配；更换模型后应重新向量化。
- 模型不可用或不匹配时使用关键词索引，不拿另一模型的向量强行匹配。
- 首页搜索工具无有效索引或无命中时使用原有全文搜索；损坏的可选索引不阻断正常检索。
- 首页不会自动将上次打开的书当作上下文，也不会将全书库静默发送给大模型。
- 检索片段会作为参考资料发送给用户选定的 AI 服务；使用远程向量模型时，查询也会发送给对应向量服务。
- 索引检索返回的是相关片段，不是完整章节或全书总结；技能仍遵守各自的原文范围和防剧透约束。

回归测试覆盖语义命中（无字面匹配）、模型不匹配降级、损坏／缺失索引、跨书隔离、搜索工具实际接入及阅读技能范围。
