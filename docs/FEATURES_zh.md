## 1. 第一次使用

1. 在书架右上方「导入书籍」选择文件或文件夹，勾选后导入；桌面也可拖入文件 / 文件夹。
2. 点击封面开书，在阅读区打开菜单，调整「样式」及更多阅读设置。
3. 需要离线查词时，在「设置 → 自定义字典」导入自己的字典。
4. 需要 AI 时，先在「设置 → AI 设置」配置供应商和模型，再使用阅读 AI 或首页 AI。
5. 需要朗读时，在「设置 → 朗读」选择服务、保存接口、获取并试听声音。
6. 需要跨设备时，在「设置 → 同步」配置 WebDAV 或对象存储；先备份再连接已有云库。

普通书籍阅读不要求配置 AI、同步或在线朗读。字体、模型及在线服务是否可用取决于本机文件、网络和所选服务。

## 2. 导入、书架与远程书库

| 功能 | 操作与结果 | 边界 |
| --- | --- | --- |
| 本地导入 | EPUB、PDF、MOBI、AZW3、FB2、TXT、`.md` / `.markdown`、文字 UMD；可多选 | 兼容扩展名不保证每个损坏、加密或特殊排版文件都可解析 |
| 文件夹导入 | 扫描子文件夹，展示兼容文件供勾选 | 保留原始文件；仅导入可访问的文件 |
| TXT / Markdown | 导入时转换成 EPUB，之后沿用阅读、笔记和同步流程 | 不修改原文件；Markdown 不运行 Mermaid、LaTeX 或脚本 |
| 书架整理 | 新建文件夹、批量移入文件夹、标签、置顶，书籍菜单管理 | 书籍正文与书架记录分别管理；仅云端记录需先下载正文 |
| 格式标签 | 可识别时显示 TXT／MD／UMD 原格式，否则显示存储格式；同时显示扫描版标识 | 显示元数据不改变实际文件及同步校验值 |
| 远程书库 | 「设置 → 远程书库设置」连接独立 WebDAV，浏览、下载及勾选导入远程文件夹，包含子文件夹 | 不是书库同步，不修改服务器书籍；取消时保留已导入书籍 |

文字 UMD 在后台转换为 EPUB，保留章节、元数据和支持的封面；文件上限 64 MiB，解压文本上限 32 MiB，暂不支持图片／漫画 UMD。远程目录在后台解析，响应上限 32 MiB，书籍下载仍保留 512 MiB 限制。

Markdown 建议使用 UTF-8：一级标题优先作书名，标题生成目录；支持常见格式、表格、代码块和静态内容。Base64 图片可内嵌；相对路径图片不会自动读取相邻目录，网络图片不自动下载；完整图文书建议打包成 EPUB。文件上限 64 MiB。详见 [Markdown 书籍](MARKDOWN_BOOKS.md)。

源码：[格式清单](../lib/service/book_formats.dart)、[导入界面](../lib/widgets/bookshelf/book_import_picker.dart)、[书架](../lib/page/home_page/bookshelf_page.dart)、[远程书库](../lib/service/remote_library/webdav_library.dart)、[Markdown 转换](../lib/service/convert_to_epub/markdown/convert_from_markdown.dart)。

## 3. 普通文字书阅读

正文阅读提供目录、书内搜索、书签、阅读进度与章节导航。底部进度面板可拖动进度，切换上一章 / 下一章、上一页 / 下一页；章节进度与本章页进度含义不同。

「样式」调整字体、字号、粗细、模拟加粗、行距、段距和背景；更多设置调整边距、横排 / 竖排、翻页行为等，实际排版受书籍和阅读内核影响。支持导入 TTF / OTF 字体，实际字重受字体文件支持程度影响。中文字体旁的「原文 / 简体 / 繁体」只转换显示，不改写原书。

| 设置 | 初始值 / 范围 | 生效方式 |
| --- | --- | --- |
| 字体粗细 | 0.5–2.0，步进 0.1 | 按字体支持显示；固定字重可尝试模拟加粗 |
| 滚动翻页比例 | 默认 80%，可设 80%–100% | 控制一次滚动翻页移动量，不限制连续手动滚动 |
| 仅点击翻页 | 默认关闭 | 移动端避免滑动翻页，仍可选词及连续滚动 |
| 长按选择整段 | 默认关闭 | 默认自动匹配词语；可改为整段，之后仍可调整选择手柄 |
| 阅读亮度 | 默认跟随系统；手动 20%–100% | Android 调窗口亮度；其他平台应用内调暗，本机保存 |
| E-Ink | 默认关闭 | 关闭应用内过渡和动态效果，使用适合墨水屏的实色界面 |

桌面阅读支持符合焦点条件的键盘翻页；输入框、文本拖选和弹层不会被当作普通翻页。全平台统一开书／返回封面过渡，E-Ink 和关闭动画时跳过；iOS 保留侧滑返回，拖动手柄后及时更新选词菜单。页面背景与应用主题分别设置。

MOBI 对可靠配对的旧式注释列表和上标图标恢复弹窗；AZW3 补齐注释语义，转换链接错误时可采用明确内嵌的注释文字。对应注释在正文中隐藏，无法可靠识别的 MOBI 内容保留显示。原书文件与标注使用的文字节点位置保持不变。

源码：[阅读设置](../lib/page/settings_page/reading.dart)、[样式面板](../lib/widgets/reading_page/style_widget.dart)、[偏好默认值](../lib/config/shared_preference_provider.dart)、[键盘翻页](../lib/service/reader_keyboard.dart)、[亮度](../lib/service/app_brightness.dart)。

## 4. PDF、扫描图片书与 OCR

PDF 使用原版阅读控制。EPUB / MOBI / AZW3 / FB2 导入时抽样识别扫描图片书；打开书时读取已保存的分类，书籍菜单可手动纠正分类。普通文字书继续使用原菜单。

### 原版页面

- 适屏、适宽，100%–1500% 缩放，旋转、移动视口，单页 / 连续卷轴。
- 自动或手动裁边、分格和阅读顺序；布局按书保存，不覆盖原文件。
- 图像增强可调整墨色、对比度、加深、增白、锐化和水印减淡，并对照原图。
- 「更多原版阅读设置」提供页面边界线、卷轴间隔、灰度、放大后先平移再翻页，以及左右 / 反向 / 上下 / 仅点击导航。
- 自动翻页默认关闭；开启默认 30 秒，可设 5–600 秒。后台、菜单、输入和文字选择期间暂停。
- 支持的独立水印图层可仅在显示时隐藏；扫描图像水印减淡是另一种处理，不能保证所有水印均能消除。应用灰度不增加屏幕硬件灰阶。
- E-Ink 模式可设置手动 / 每 N 页刷新；真正的硬件刷新依赖设备接口。

### 从图像取得文字

| 入口 | 文字来源 | 结果 / 限制 |
| --- | --- | --- |
| 文字重排 | 当前页已有文字层 | 在阅读区显示可选择文字；不是全书转换 |
| OCR 重排 | 本地模型识别当前页图像 | 启用裁边时处理裁后整页；不是仅处理当前分格或放大视口 |
| 提取 | 手动选择的区域 | 结果进入可编辑 AI 输入框，编辑后再发送，不自动发送 |

「设置 → OCR 模型」推荐 PP-OCRv4 中英文，另有 v5 中英文轻量、v3 中英文、v3 英文。模型按需下载，可切换上游 / Gitee；v5 上游为 ModelScope，v3 / v4 为 Hugging Face。文件通过大小和 SHA-256 校验后使用；识别在本机执行，不需要 OCR API Key。小字、复杂分栏、模糊页面仍需校对。

重排结果可接入选词等阅读工具；没有文字层且未识别的原图不能直接当作可选文本。本文不承诺全书 OCR、全书重排导出或所有扫描版均具备与文字书相同的搜索 / 标注 / 朗读效果。

源码：[原版控制](../lib/widgets/reading_page/pdf_reading_controls.dart)、[布局](../lib/widgets/reading_page/document_layout_editor.dart)、[重排](../lib/widgets/reading_page/document_reflow_reader.dart)、[提取](../lib/widgets/reading_page/document_extraction_panel.dart)、[OCR 模型](../lib/service/ocr/ocr_models.dart)。

## 5. CSS、划词、标注与笔记

「设置 → CSS 设置」管理命名方案、图形参数、自定义代码和正则高亮。提供 32 个方案位置；开启总开关和需要的方案，可使用多套组合；当前书可跟随默认组合或独立选择。修改共享方案会影响其他使用该方案的书。新增、复制、导入方案默认关闭，导入占用空位而不直接覆盖。

正则高亮是显示规则，不是保存的笔记或批注；CSS 不改写源书。CSS 引用的远程字体 / 图片可能联网，效果受阅读内核和原书样式影响。

选中正文后可标注、写笔记、查词、翻译、搜索和调用 AI；具体按钮受「设置 → 划词工具栏」的开关、排序及阅读模式控制。该页可编辑标注颜色和 AI 划词命令的名称、图标、提示词。AI 划词模板与 AI 阅读技能分别管理。

每个 AI 划词命令可选择「结合上下文」或「仅选中文字」，以及是否联网。AI 知识的补充「联网搜索」在同一对话中检索词典 / 百科并整理来源，不需要单独搜索 API Key；AI 回答仍应核对。

快速标注可在保存后显示选词菜单，默认关闭；连续跨页标注按已有合并规则处理。笔记页可查看、搜索、编辑书摘；导出支持复制、Markdown、TXT、CSV。支持的阅读位置链接可跳回仍存在的书籍及相应位置；导出文本不等于备份整本书。

源码：[CSS 配置](../lib/models/custom_css_profile.dart)、[划词设置](../lib/page/settings_page/selection_toolbar.dart)、[快速标注](../lib/service/book_player/quick_mark_service.dart)、[笔记导出](../lib/service/notes/export_notes.dart)、[阅读位置链接](../lib/service/notes/reading_link.dart)。

## 6. 本地字典、选词搜索与翻译

### 本地字典

在「设置 → 自定义字典」导入、命名、启用 / 停用或删除字典。支持 MDX 1 / 2、StarDict 配套文件和包含一部字典的 ZIP。查词时查询启用字典的实际词目，支持修改查询词；是否双向取决于原词目，不支持从中文释义反向检索所有词条。

只显示文字，不执行字典脚本，不加载 MDD、图片或音频。MDX 3、LZO、加密记录等不支持；不是所有商业字典均兼容。查词在本机，不自动改用在线翻译；字典数据不参加书库同步或当前备份。详见 [字典格式与限制](LOCAL_DICTIONARIES.md)。

### 搜索和翻译

「设置 → 选词搜索」配置内置或自定义搜索地址，自定义地址使用 `{query}` 占位。查询通过内置浏览器打开，缩放默认 100%，可设 50%–200%；查询文字会发送到搜索站点。

「设置 → 翻译」当前可选 Google 翻译（免费）、AI、DeepL / DeepLX，以及 Google / Bing / 百度 / 有道网页。网页引擎用于选文；全文翻译使用 Google 免费、AI 或 DeepL，避免把网页窗口误当作逐段全文翻译。百度 / 有道目标语言在对应网页内选择。

可选择目标语言和 AI 翻译模型、配置 DeepL Key / 地址；DeepLX 可用基础或完整 `/translate` 地址。「选中文本后自动翻译」默认关闭。全文翻译在书页展示原文 + 译文或仅译文，并非导出整本译书；待译文本发送给所选服务。扫描页先取得文字层或 OCR / 重排结果。

源码：[字典](../lib/service/dictionary/local_dictionary.dart)、[搜索设置](../lib/page/settings_page/selection_search.dart)、[翻译界面](../lib/page/settings_page/translate.dart)、[可见引擎](../lib/service/translate/index.dart)、[免费翻译传输](../lib/service/translate/microsoft_free.dart)。

## 7. AI 供应商、对话与阅读技能

应用的 AI 模型由用户在「设置 → AI 设置 → 供应商配置中心」选择，不固定使用群机器人所用的 Qwen 模型。填写接口、模型和 API Key 并测试连接；各模型可保存温度、输出上限、历史轮数和推理参数。供应商决定可用模型、收费及参数支持；RPM 只控制本机调用节奏。`isOhosStore` 商店构建会隐藏 AI 设置和阅读技能入口，具体以安装包及构建开关为准。

AI 对话可继续追问、恢复历史、调整字号。支持工具的模型可在已启用权限内查询书架、笔记、阅读历史、目录和正文，计算、查看时间，生成导图或书架整理方案。整理方案需要在应用中确认应用；提示词本身不代表模型取得了整本书或已经修改书架。

阅读技能入口默认显示。内置与自定义技能可开关、排序、修改提示词、恢复默认；「技能模板先填入输入框」默认关闭，点击直接发送；开启后先编辑再发送。默认提示词随应用语言，用户修改不被自动翻译或覆盖。

| 内置技能 | 实际提供的阅读范围 |
| --- | --- |
| 本章总结、概念解析、论证分析、金句摘录、阅读指南、词汇助手、思维导图 | 选文或当前章可取得的正文，不自动混入其他章的检索片段 |
| 智能翻译 | 选中文本 |
| 全书总结 | 沿目录取得章节，复用有效索引文本并补取缺失部分；压缩到上下文预算，不等于逐字读完全书 |
| 人物追踪 | 已读章节和当前章截至阅读位置的文字；无法取得已读范围时不替换为整章 |
| 普通书内问答 | 当前书有效索引中的关键词 / 语义相关片段 |
| 首页书籍问答 | 工具先确认书籍再检索；需模型支持工具调用并启用相应工具 |

思维导图可全屏、缩放、平移、展开 / 收起节点，导出 PNG、SVG、Markdown、FreeMind、JSON。AI 生成内容需核对，尤其原文引述、人物事实及来源。具体上下文见 [AI 与索引说明](AI_INDEX_USAGE.md)。

源码：[技能清单](../lib/service/ai/readany_skills.dart)、[技能执行](../lib/service/ai/reading_skill_execution.dart)、[工具注册](../lib/service/ai/tools/ai_tool_registry.dart)、[供应商设置](../lib/page/settings_page/ai_provider_detail_page.dart)、[导图导出](../lib/service/ai/mindmap_export.dart)。

## 8. 向量模型与语义检索

嵌入模型负责将书中文字转为检索向量，大语言模型负责组织回答，OCR 模型负责识别图像文字，三者配置独立。

「设置 → 向量模型」默认启用本地模式，默认模型 BGE Small ZH v1.5；另有 BGE Small EN、all-MiniLM-L6-v2、Multilingual E5 Small，或用户配置的远程 embeddings 服务。模型按需下载并校验；缺模型不会偷偷下载。远程服务会接收待索引片段及查询，可能收费。

1. 下载可用模型并确保书籍正文在本机。
2. 在书籍菜单选择向量化 / 重新向量化，由同一后台队列处理。
3. 使用阅读 AI / 书籍搜索工具检索；自动导入向量化默认关闭，可按需开启。
4. 需要停止时，使用书架任务栏或设置中的「停止向量化」：关闭自动索引并停止当前及排队任务，保留已完成索引、模型和书籍。

切换模型或修改原书需重新建索引；仅升级安装包不应使未变更的有效索引失效。模型不匹配 / 不可用时回退关键词，不比较不同模型的向量；索引损坏不应阻断普通搜索。

**索引文件仅本机保存，不参加 WebDAV / S3 书库同步。** 其他设备自行建立；旧云端索引不会因升级而自动删除。本地嵌入不代表远程 AI 问答离线：提供给远程聊天服务的相关片段仍离开设备。

源码：[模型目录](../lib/service/knowledge/local_embedding_models.dart)、[索引队列](../lib/service/knowledge/book_knowledge_index_queue.dart)、[检索](../lib/service/knowledge/book_knowledge_retriever.dart)、[书籍检索工具](../lib/service/ai/tools/book_content_search_tool.dart)。

## 9. 朗读、声音与缓冲

「设置 → 朗读」提供系统语音、Edge TTS、DashScope、Xiaomi MiMo 和 OpenAI 兼容语音。修改接口后先保存，再获取声音 / 试听；服务所需模型、密钥和音色按服务表单配置。系统 TTS 仅接入 Android、iOS、macOS、Windows；Linux / OpenHarmony 需主动选择支持的在线服务。

阅读区提供播放 / 暂停、回到朗读位置、从当前处朗读；在线音频播放最高 4×，2× 之后为 3×、4×档位。系统声音和指令式语速受引擎影响，不保证精确倍率。后台朗读及通知控制受操作系统权限和电源管理影响。

OpenAI 兼容和 MiMo 的风格设置可编辑自然叙述、睡前轻读、小说演绎等模板；效果依赖接口支持。风格描述作为指令，不应当作正文朗读。MiMo 文字设计音色不是声音克隆。

### 在线朗读参数

入口：「设置 → 朗读 → 在线朗读缓冲与缓存」。下面列出界面档位；导入参数还会进行边界校验。

| 参数 | 默认 | 界面可选值 | 含义 |
| --- | --- | --- | --- |
| 提前缓冲量（段） | 3 | 0、1、3、5、8、12 | 不含正在播放的段；0 不提前合成 |
| 单次合成字数上限 | 240 | 100、240、400、600、1000、1500、2000 | 尽量沿句子 / 自然段拆分，是上限而非目标长度 |
| 预合成并发数 | 2 | 1、2、3、4 | 优先首段，其余请求遵守并发上限 |
| 段落停顿（毫秒） | 0 | 0、100、200、300、500、1000、2000、3000 | 仅自然段末尾额外停顿，不在长段拆分处停顿 |
| 缓存保留（分钟） | 10 | 0、5、10、30、60、120 | 立即生效；0 表示停止时清理 |

前四项停止后重新开始生效，暂停 / 继续保留当前会话参数。音频仅内存缓存，上限 32 MiB，退出不保留；「清理音频缓存」不打断当前播放，保留已准备队列。系统 TTS 不应用这些在线参数。增加预合成和并发可能增加用量或触发限流。

朗读配置通过全局设置文件 / modu 链接迁移；系统声音跨设备可能需重新选择。「清除朗读设置」停止朗读并移除 TTS 配置，恢复默认，不清空书库、AI 或同步设置。

源码：[朗读设置](../lib/page/settings_page/narrate.dart)、[服务清单](../lib/service/tts/tts_service.dart)、[系统平台](../lib/service/tts/system_tts_support.dart)、[参数界面](../lib/widgets/settings/tts_buffer_settings.dart)、[默认值与校验](../lib/models/tts_buffer_settings.dart)。

## 10. 阅读历史

## 11. WebDAV / 对象存储同步

「设置 → 同步」可选 WebDAV 或对象存储。WebDAV 填上级地址、账号、密码，数据位于其下 `modu` 目录，地址末尾不要再次加 `/modu`。对象存储支持 OSS、COS、S3、R2、雨云 ROS、Kodo、BOS、TOS 预设和 MinIO 等自定义 S3 兼容地址；填写 Endpoint、区域、桶、前缀和访问凭据后测试。高级参数包括临时令牌、寻址、签名和列举版本。

升级沿用原 WebDAV 配置；主动切换服务前关闭同步并等待任务完成，两套连接分别保留，切换不会自动搬迁旧云端书籍。先下载仅云端正文并做好备份。详见 [对象存储配置](OBJECT_STORAGE_SYNC.md)。

| 范围 | 行为 |
| --- | --- |
| 书籍、笔记、书签、文件夹、标签、阅读记录 | 按稳定标识合并；阅读位置看最近真实操作，而不是简单选最大百分比 |
| 字体、背景、本地字典、向量索引 | 不参加书库同步 |
| 自动同步 | 初始偏好开启，但云端同步连接初始关闭；必须先配置并启用服务 |
| 阅读时定时同步 | 默认关闭；默认间隔 5 分钟，可选 1 / 2 / 3 / 5 / 10 / 15 / 30 / 60 分钟，需云端及自动同步都开启 |
| 前台限制 | 定时任务仅在前台阅读工作，离开 / 锁屏暂停；返回等完整间隔，不补发，不重叠 |
| 仅 Wi-Fi | 按同步偏好限制联网；无法连接时保留待同步的本地改动 |
| 服务配置同步 | 独立开关，默认关闭；使用至少 12 字符的单独密码加密支持的服务配置 |

坚果云自动同步合并重复触发，后续至少间隔 10 分钟；同机同账号使用半小时 480 次请求预算。手动同步仍受预算和服务端冷却限制，重启不重置；其他设备也消耗账号额度。所有 WebDAV 遵守 429 / 503 与 Retry-After。

服务配置使用 AES-256-GCM 加密；同步加密密码不是服务器登录密码，不被同步。不含 WebDAV / S3 连接凭据，也不把整个书库、正文或数据库加密。忘记密码不能恢复服务密钥。书架出现记录不代表正文已下载；各设备尽量使用同一版本。

源码：[同步设置](../lib/page/settings_page/sync.dart)、[记录合并](../lib/service/sync/row_sync_engine.dart)、[S3 配置](../lib/service/sync/s3_config.dart)、[定时阅读同步](../lib/service/sync/reading_sync_scheduler.dart)、[服务加密](../lib/service/sync/ai_settings_sync.dart)。

## 12. 备份、恢复与 ANX 迁移

| 功能 | 入口 | 内容与恢复方式 |
| --- | --- | --- |
| 全局设置备份 | 设置 → 全局设置备份 | JSON 或 modu 链接，可选模块；恢复文件包含的设置，不迁移书籍 / 笔记 / 聊天 / 进度 |
| 本地书库备份 | 设置 → 同步 → 数据库备份 | ZIP，包含本机正文、封面、字体、背景、数据库、AI 历史及一般设置；恢复会替换现有书库，不是合并 |
| ANX Reader 导入 | 设置 → 高级 → 导入 ANX Reader 的备份文件 | schema 7 的 ZIP，合并支持的已下载书籍、封面、笔记、进度、时长、文件夹与标签 |

全局设置不包含字体 / 背景 / 字典 / 模型文件；默认不包含账号、密码和 API Key。打开凭据选项后 JSON / 链接可还原出明文，需私密保存。关闭导入凭据选项时保留本机账号密钥；导入云端设置后，云端同步和自动同步需手动重新开启。

数据库备份应先下载所有要保留的正文。服务凭据默认排除，可选加密设置部分；不等于整个 ZIP 都加密。恢复前备份现状，等待同步 / 向量任务结束，导入后完全关闭并重新打开应用。

ANX 导入不迁移账号、应用设置、AI 历史或缺失正文的书；不接受单独 DB、加密 ZIP 和未知数据库版本。导入前建立本机数据库快照，重复导入按实际文件去重；这是一次性迁移，不是两款应用持续同步。

源码：[设置迁移](../lib/service/config_transfer/global_settings_transfer.dart)、[备份界面](../lib/widgets/settings/database_backup_section.dart)、[ANX 导入](../lib/service/local_data/anx_database_import.dart)。

## 13. 更新、日志与问题反馈

「设置 → 关于默读 → 版本检查与更新」统一选择 GitHub / Gitee 检查和下载，默认 GitHub；切换来源后重新检查。检查新版不等于自动安装。覆盖升级前备份，不要先卸载或清空数据。各平台签名、安装及运行条件见 [发布和安装说明](RELEASING.md)；源码存在某平台支持不等于该平台已完成实机验收。

「设置 → 存储」查看占用并清理可再生成的临时数据；模型、书籍和已完成索引不属于普通缓存清理。高级设置提供 TXT 分章规则、文件校验值管理、日志、网络代理和 JavaScript 等入口；启用脚本前确认书籍可信。

「设置 → 问题反馈与功能建议」只有 Bug 和功能建议两种类型，可查看已有问题和个人反馈。填写复现步骤、预期 / 实际结果、版本与平台，预览后打开 GitHub 提交；长报告或附诊断时复制到剪贴板供手动粘贴。截图 / 可公开示例可在 GitHub 添加。

崩溃诊断默认不附带、不上传。用户勾选时提供已脱敏的可用错误与检查点，不是全部普通日志、正文或配置；提交前仍应检查。普通日志在高级设置中查看。GitHub issue 是公开内容，不应放私人书籍或凭据。

源码：[更新](../lib/service/update/app_update.dart)、[反馈界面](../lib/page/settings_page/bug_report.dart)、[崩溃诊断](../lib/service/feedback/crash_diagnostics.dart)、[平台构建开关](../lib/utils/env_var.dart)。

## 14. 离线与联网速查

| 使用场景 | 处理地点 / 联网行为 |
| --- | --- |
| 已下载书籍阅读、笔记、本地字典 | 本机；书籍内远程资源和用户开启的脚本 / CSS 资源另行决定 |
| 本地 OCR / 本地嵌入 | 下载模型需要网络；识别 / 向量推理在本机 |
| 远程 AI / embeddings / 在线 TTS / 翻译 | 向用户选择的服务发送所需正文、片段或查询 |
| 选词搜索 / AI 知识联网搜索 | 将查询发到搜索站点或词典 / 百科；整理过程可能调用所选 AI |
| 同步 | 向配置的 WebDAV / 对象存储发送同步范围内数据 |
| 公开反馈 | 用户预览后提交 GitHub issue；诊断按用户勾选附带 |

应用 AI 配置与 QQ 群助手属于不同服务；群助手的线上模型、权限和已部署版本不能从应用文档推断。完整网络和数据范围见 [隐私说明](../PRIVACY_zh.md)。

本文完成的是代码与文档核对；没有在所有平台逐项执行导入、OCR、朗读、同步和更新实机测试。历史测试记录仍保留原日期，不应当作本次新验收。
