# 索引同步与阅读控制

## 跨设备向量索引

在「设置 → 同步」启用「同步向量化数据」，默认关闭；每台设备单独开启，恢复设置备份不会代为开启。

1. 电脑完成书籍向量化后，同步到 WebDAV。
2. 手机下载同一份书籍文件，开启上述开关，再同步。
3. 接收端校验通过后可以复用索引，不需要再次向量化整本书。语义查询仍需要与索引匹配的模型；模型文件和 API Key 不包含在索引里。没有单独指定模型的书籍，会采用导入索引所记录的受支持本地模型。

匹配依据为实际书籍文件字节的 SHA-256，不使用书名或设备数据库编号。传输文件另有 SHA-256 校验，检查书籍标识、片段、向量维度和完整性后，才转换成本机书籍编号并写入。下载期间书籍被替换、删除或关闭开关时，不写入该索引。已有有效本地索引不会被云端覆盖，未完成的索引不会上传。

索引包含书籍原文片段及向量，会存储到所配置的 WebDAV 的 `modu/knowledge-v1` 下。它不使用 API Key 同步的加密密码；请使用受信任的服务器和 HTTPS。单本传输上限为 128 MiB，超过时明确报错；可以关闭此开关继续同步其他数据。关闭开关不删除已保存的索引。不自动清理历史索引附件。

## 快速标记菜单

移动端进入快速标记后，右上角工具栏新增「标记后弹出菜单」按钮，默认关闭，选择在本机记忆。关闭时松手只保存高亮；开启时保存成功后弹出选中菜单，操作的是实际保存（包括跨页合并后）的批注。普通选词菜单不受影响。

## 后台朗读

Android 媒体通知接入播放/暂停、上一段、下一段和停止。跨章文本加载与可见页面定位分离，朗读不等待页面完成布局；返回前台后补齐高亮。后台朗读位置单独记录。停止时清理播放器的异常不会阻止其余资源清理和下一次启动。

自动化覆盖跨章导航、后台页面不渲染、停止竞争、播放器清理异常、通知状态，以及索引校验/错配/取消/并发和快速标记菜单。WebDAV 使用内存服务与临时文件测试，并非真实服务器实测。长时间锁屏、厂商省电行为及通知交互仍需 Android 真机验证；此轮没有连接到测试设备。
