# 原位读取实施记录

更新：2026-11-08

## 使用方式

- 设置 → 阅读 → 添加书籍，开启“原位添加书籍”（默认关闭，仅本机保存）。
- 加号添加文件或文件夹时读取原文件；拖入始终导入内部副本。
- 原位支持 EPUB、PDF、MOBI、AZW3、FB2。TXT、Markdown、UMD 沿用普通导入转换。
- 开启后显示“内部／原位”标签，以及文件缺失或授权失效状态。
- 书籍菜单支持关联原书、复制到默读、下载内部副本和仅从本机移除。重新关联校验内容 MD5；不匹配时不会覆盖旧记录。
- 原位原书不上传，阅读进度、朗读位置、笔记、书签、封面、OCR 校对等资料沿用现有同步设置；无本机原书也能同步 OCR 和微信读书资料。
- 删除外部原书的操作不存在。书架删除沿用现有软删除规则；云端副本须单独勾选，离线删除任务持久化，发布删除记录后执行，恢复书籍会取消旧任务。
- 设置中提供默认打开方式指引。系统外部打开仍导入副本，需要原位时从加号授权原文件。

## 实现

本机来源独立保存在 `book_sources.json`，云端书籍路径继续作为资源键。本机路径、授权、移除状态、删除队列不进入同步和备份。来源切换不改变书籍身份和阅读资料；同内容的不同文件名不触发错误的文件替换回收。

Android 使用 SAF 只读持久授权；iOS 沿用书签；macOS 新增只读 security-scoped bookmark；Windows/Linux 保存本机路径；HarmonyOS 使用文件选择器及只读持久权限。

Android/HarmonyOS 描述符通过只读流接入，按块定位读取，不在导入时复制原书。每次读取独立复制描述符并释放，避免并发读取共享偏移。阅读服务、MD5、索引校验、复制和分享使用统一通道。分享时才生成临时副本。
