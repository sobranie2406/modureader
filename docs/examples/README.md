# 截图示例书

《阅读，让思考慢下来》是默读项目为公开文档创作的简短示例，不是私人藏书，不是模型实际生成的回答。内容随项目按 GPL-3.0-or-later 提供。

- `modu-reading-demo.epub`：可以直接导入默读，包含三个章节及 EPUB 目录。
- `make_screenshot_book.py`：保留全部原始文字和 EPUB 生成逻辑，运行 `python3 docs/examples/make_screenshot_book.py` 可重新生成。

当前 README 的横排阅读、AI 侧栏与目录截图于 2026-09-21 拍摄自 macOS 正式版 1.1.1+10033，使用此示例书展示真实界面，没有合成 AI 回复或修改截图中的 UI。截图仅展示阅读与 AI 操作入口，不作为 RAG 检索结果或模型回答质量的证明。古籍竖排截图的来源另见 [截图说明](../images/README.md)。
