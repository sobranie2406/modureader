# 批注整理

两个入口，都在「插件 → 批注整理」的贡献列表里：

- **汇总批注**：把书库里的划线与批注按书分组，生成一段可粘贴的复习清单。
- **查找相关批注**：在阅读界面选中文字后运行，跨书库搜索相关书名与批注。

## 演示的宿主接口

| 接口 | 权限 | 用途 |
| --- | --- | --- |
| `modu.notes.list({limit})` | `note:read` | 读取划线与批注（含章节、我的批注） |
| `modu.search.library({query,limit})` | `search:library` | 一次搜索书籍与笔记 |
| `modu.share.text({text,subject})` | `share:text` | 调起系统分享面板 |
| `modu.library.tags` / `library.tag` | `library:read` / `library:write` | 见下方说明 |

## 权限

四项都是**运行期权限**，默认关闭：

- `note:read`：笔记是私密内容，未解锁的私密书籍笔记不会返回。
- `search:library`：全库搜索会扫描书名与笔记。
- `share:text`：分享会把内容交给其他应用，需要单独同意。
- `library:write`（本版未启用动作）：保留在清单中说明如何扩展；开启后才允许打标签或移动分组。

## 设置

- **条数上限**：最多读取多少条笔记（1–50）。
- **包含我的批注**：关闭后只列出划线原文。
- **生成后调用系统分享**：默认关闭，避免一次点击就把内容送出应用。

## 隐私说明

脚本只能拿到「已授权可读」的书名与笔记文本。宿主不提供书籍文件路径、数据库句柄或未解锁的私密书籍内容。
