# 阅读统计卡

在「插件 → 阅读统计卡」中点击「生成阅读报告」，弹出窗口显示最近一段时间的阅读时长与书目排行，并默认复制成一段文字。

## 演示的宿主接口

| 接口 | 权限 | 用途 |
| --- | --- | --- |
| `modu.reading.stats({days})` | `reading:read` | 汇总每日阅读秒数，按书排行 |
| `modu.clipboard.write({text})` | `clipboard:write` | 把报告复制到剪贴板 |

## 权限

两项都是**运行期权限**，安装后默认关闭，需要在插件详情的「权限」中逐项开启：

- 阅读时长与本机隐私相关，脚本只能拿到时长合计和书名，拿不到书籍正文、笔记或文件路径。
- 剪贴板写入会影响其他应用粘贴的内容，默认同样需要手动开启。关闭后报告仍会显示，只是不会复制。

## 设置

- **统计区间**：7 / 30 / 90 / 365 天。
- **书目数量**：排行显示前几本（最多 20）。
- **同时复制到剪贴板**：关闭后只显示报告。

## 数据来源

只读取本机 `tb_reading_time` 的聚合结果，不上传、不写盘，私密书籍的阅读记录不会出现在结果里。
