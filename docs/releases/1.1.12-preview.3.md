# 默读 1.1.12 Preview 3 · Android ARM64

版本：`1.1.12-preview.3+10075`。本次为 Android ARM64 预发行版，正式版保持 1.1.11。

## 更新内容

- 新增「停止向量化」：书架后台任务栏和「设置 → 向量模型」均可停止当前及排队任务，同时关闭自动向量化，避免重启后自动续跑。保留已完成索引、书籍及下载模型。
- 关闭自动向量化时取消自动任务，不影响手动任务；修复扫描期间关闭开关仍继续入队，以及取消后不能手动重新入队的问题。
- 修复蓝牙翻页笔接入/断开时触发不必要的 Android 阅读窗口重建；重新同步按键状态，并在返回阅读时恢复符合当前设置的沉浸显示。
- 修复部分 EPUB 脚注回链被误判，导致朗读跳过正文段落的问题。
- 优化搜索及网页翻译弹窗的窄屏布局，减少横向溢出；网页翻译增加 50%–200% 页面缩放并记住设置。

## 对应源码

Flutter 3.47.2，构建使用显式版本参数（不改变主线正式版默认版本）：

