# Modu 1.1.12 Preview 3 · Android ARM64

> Historical release record for `1.1.12-preview.3+10075`; this is not certification of the latest 1.2.0 release. See the [documentation index](../README.md).

Version: `1.1.12-preview.3+10075`. This was an Android ARM64 prerelease; the stable version remained 1.1.11 at the time.

## Changes

- Added “Stop vectorization” to the bookshelf background-task bar and Settings → Vector models. It stopped active and queued tasks and disabled automatic vectorization to prevent automatic resumption after restart. Completed indexes, books and downloaded models were retained.
- Disabling automatic vectorization cancelled automatic tasks without affecting manual tasks. Fixed tasks continuing to enter the queue after disabling the switch during a scan, and manual requeueing being blocked after cancellation.
- Fixed unnecessary Android reader-window recreation when connecting/disconnecting a Bluetooth page-turning pen. Key state was resynchronized, and immersive display was restored according to current settings on returning to reading.
- Fixed some EPUB footnote backlinks being misclassified, causing narration to skip body paragraphs.
- Improved narrow-screen layouts in search and web-translation popups to reduce horizontal overflow. Web translation added persistent 50%–200% page zoom.

## Download and installation

Download `Modu-1.1.12-preview.3-10075-android-arm64.apk`. It retained Modu's dedicated signature and could install over versions with the same signature while preserving books and settings. Backing up before updating was recommended.

## Corresponding source

The source tag was `android-1.1.12-preview.3`. This tag was dedicated to the Android preview package built and verified locally; it did not trigger stable package builds for all platforms.

Flutter 3.47.2; the build used explicit version arguments without changing the mainline stable version default:

```sh
flutter build apk --release --split-per-abi --target-platform android-arm64 \
  --build-name 1.1.12-preview.3 --build-number 10075
```

The repository's LICENSE, NOTICE, UPSTREAM.md and dependency licenses were retained; signing keys were not stored in the repository.
