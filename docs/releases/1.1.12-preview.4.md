# Modu 1.1.12 Preview 4

> Historical release record for `1.1.12-preview.4+10076`; this is not certification of the latest 1.2.0 release. See the [documentation index](../README.md).

Version: `1.1.12-preview.4+10076`. This release offered only Android ARM64, Windows x64 and macOS ARM64; the stable update entry remained on 1.1.11 at the time.

## Changes

- Added original-page reading controls for PDF and image EPUB: cropping, panels, region reading order, zoom, rotation, panning and continuous scrolling.
- Added automatic cropping, whitespace margins and image enhancements, including ink tone, contrast, darkening, whitening and sharpening, with per-book layout and viewport-position persistence.
- Image EPUB detection sampled content during import; opening a book read the stored result without waiting for another sample. Ordinary text EPUB, TXT, Markdown and similar books retained Preview 3 reading menus. The main interface and global settings layout were unchanged.
- Added “Online search” at the end of AI Knowledge replies, before “Regenerate” and “Copy.” It looked up the original term in the same conversation while preserving the input draft. The prompt became “For an online lookup, click the Online search button below.”
- Included Preview 3 improvements to stopping vectorization, Bluetooth page-turner window restoration, EPUB footnote narration and web-popup layouts.

## Downloads

- Android ARM64: `Modu-1.1.12-preview.4-android-arm64.apk`
- Windows 64-bit: `Modu-1.1.12-preview.4-windows-x64-setup.exe`
- macOS Apple Silicon: `Modu-1.1.12-preview.4-macos-arm64.dmg`

Each package had a SHA-256 checksum file. Backing up the library and settings before installation was recommended. Android retained Modu's dedicated signature and could install over versions with the same signature; on macOS, drag the app into Applications; on Windows, use the installation wizard.
