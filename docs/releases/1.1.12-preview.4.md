# 默读 1.1.12 Preview 4

版本：`1.1.12-preview.4+10076`。本次仅提供 Android ARM64、Windows x64 和 macOS ARM64，正式版更新入口保持 1.1.11。

## 更新内容

- PDF 和图片 EPUB 增加原版阅读功能：裁边、分格、区域阅读顺序、缩放、旋转、平移及连续卷轴阅读。
- 增加自动裁边、留白和图像增强，支持墨色、对比度、加深、增白、锐化等调整，按书保存版式和视口位置。
- 图片 EPUB 在导入时抽样识别，打开书籍直接读取结果，不再抽样等待。普通文字 EPUB、TXT、Markdown 等书籍保留 Preview 3 的阅读菜单，主界面和全局设置布局不变。
- AI 知识回答末尾增加「联网搜索」，位于「重新生成」「复制」之前。点击后在同一对话中补查原词语，保留输入草稿；提示改为「如需联网补查，请点击下方的联网搜索按钮」。
- 包含 Preview 3 的停止向量化、蓝牙翻页笔窗口恢复、EPUB 脚注朗读和网页弹窗布局改进。

## 下载

- Android ARM64：`Modu-1.1.12-preview.4-android-arm64.apk`
- Windows 64 位：`Modu-1.1.12-preview.4-windows-x64-setup.exe`
- macOS Apple Silicon：`Modu-1.1.12-preview.4-macos-arm64.dmg`

每个安装包提供 SHA-256 校验文件。安装前建议备份书库及设置。Android 沿用默读专用签名，可覆盖安装同签名版本；macOS 将应用拖入 Applications，Windows 使用安装向导。
