# 阅读器翻译内容与停止控制回归

## 修复范围

- 翻译专用输出过滤器移除 `<think>` 内容（包含大小写、嵌套、未闭合与缺少起始标签的情况），不改变普通 AI 对话。
- 阅读器翻译仅在当前会话明确启动后执行，不从书籍显示偏好恢复请求。
- 只为可见段落排队，逐个请求；计算可见性时转换章节 iframe 坐标，不提前翻译屏幕外的预加载章节。
- 翻译面板及阅读界面提供停止入口。停止或关闭阅读器会撤销当前请求、清空等待队列，并丢弃迟到结果。远端已接收的计算无法保证立即终止。
- AI、免费翻译及 DeepL 请求接入取消。翻译错误不再作为正文插入，错误后停止当前会话。
